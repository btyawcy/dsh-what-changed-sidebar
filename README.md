# dsh-what-changed-sidebar

**Agent 文件改动记录，作为 [dsh-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) 的一个侧边栏 tab。** 按轮次分组，新的在最上面；点开文件看改前（红）／改后（绿）代码块，有编辑时自动弹出（可关闭）。

> 依赖 [dsh-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar)（>= 0.12.0，提供 `ctx.betterSidebar` 服务）。未安装 better-sidebar 时本插件静默跳过，不影响 DSH 启动。

## 功能

- **侧边栏 tab**：注册为 better-sidebar「+」菜单里的「改动记录」页，单实例（重复打开聚焦已有页）
- **按轮次单一视图**：轮次降序，同一文件的多处改动也是最新在最上面，不用往下翻
- **逐次修改（默认）**：文件块打开就是这一轮的每处编辑，一处一条内联对比
- **全文对照（本轮结束后）**：= diff(本轮开始前的整份文件, 本轮结束后的整份文件)。改前快照在每次编辑工具调用前抓、改后快照在 `turn/end` 落定，所以本轮进行中按钮显示为禁用的「本轮进行中…」，本轮一结束自动变成可点的「全文对照」，无需手动收起再展开。按钮只在数据确认可用后出现（打开文件块时拉一次 `whole` 请求判定），不存在能点但点不出数据的按钮。这份「每轮改完后的完整文件」也是后续回退功能的基石
- **快照落盘持久化**：两份快照按会话写入 `~/.dsh/storages/what-changed-sidebar/<会话id>.json`（原子写：临时文件 + 改名），重启 dsh web 不再丢
- **只保留最近 100 轮**：改动记录（编辑、被拒写入、shell 索引与计数）和轮次快照同口径裁剪，超过 100 轮的最老数据自动删除——长会话的投影与快照文件都有体积上界，不会越攒越多
- **修改次序编号**：多处修改时每处标「第 3/4 次修改」（按该文件整个会话的历史编号），最新那处加「最新」角标；只改一次的不加标签
- **工具类型区分**：每处编辑标注来源工具（`编辑 edit` / `写入 write` / `编辑器 str_replace_editor`），新建文件另标「新建」
- **内联对比 diff**：单流展示——删的行红底、加的行绿底，双列绝对行号（旧|新，直接对齐文件真实行号），改动点外只保留 ±3 行上下文，更远未变区折叠可展开；侧边栏窄幅下比"前后两整块上下摆"可读得多。配色走主题 token，明暗自适应；applied diff 缺失起始行号时标「块内相对行号」（新建文件的行号本来就是绝对的，不标）
- **懒加载**：投影只存轻量索引（`callId` + 元数据），全量内容按需从会话日志取回——投影体积小一个量级，展开才读
- **shell 写入按轮次列原文**：被判定为写了文件的 shell 命令落在对应轮次里（文件改动之后），折叠展示 `$ 命令原文`，同轮相同命令合并为 `×N`
- **删除/移动检测**：`rm`/`mv`/`rmdir` 命令的目标路径会被 best-effort 解析，文件块显示「已删除 / 已移动」标记（由命令推断，变量与 glob 无法解析时跳过）；文件被删前的编辑历史保留可查
- **泛化工具追踪**：任何工具只要在结果里按约定报告 `meta.diffs`（文件改动声明）就自动进改动记录——不枚举工具名，现在/将来的、第三方插件的工具零配置覆盖。不声明 diff 的结构化写入工具（如 univer 系列的 .univer / 导出产物）列在显式清单里，未安装对应插件时条目纯惰性；这类无文本对比的写入显示中性提示（不误报"加载失败"），支持其他同类工具只需在清单加一行
- **自动弹出**（可配置）：当前会话有新编辑时自动打开，同一轮只弹一次；在 better-sidebar 设置里可关（默认开）
- **tab 角标**：显示改动总数
- **跳转 / 复制**：一键在编辑器中打开、代码块与命令一键复制
- **被拒写入单列**：被沙箱或权限拒绝的写入单独成组，带原因

## 安全设计

- **路径白名单（第一道边界）**：取回路由只服务"该会话的投影里真实出现过的路径"——请求里的 path 不在白名单直接 403。没有这条，`file`/`edits`/`snapshots` 类路由就是任意文件读取原语（黑名单天生不完备，`/etc/hosts`、`~/.ssh/config` 这类拦不住）
- **trust fence（第二道边界）**：路由入口校验请求的 Host 必须是 loopback 或受信主机、浏览器标记（`sec-fetch-site`/`origin`）必须同源，防 DNS rebinding 与恶意页面跨站读文件（与 dsh-better-sidebar 同款实现）
- **敏感文件防护（第三道过滤）**：`.env`、`*credential*`、`*secret*`、`*.pem`、`*.key`、`id_rsa`/`id_ed25519` 等现代密钥名、`.ssh/`、`.aws/`、`.gnupg/`、`.kube/`、`.docker/`、`.npmrc`、`.netrc`、`.pgpass`、`.my.cnf` 等只记录"改过"，内容不进投影、不渲染、不落快照，取回路由同样 403
- **pending 阶段就不存敏感全文**：敏感路径的写入在进入投影 pending 时就剥掉文本——轮次中断时残留的 pending 条目不会把密钥带进 `session-projection-cache` 的磁盘缓存
- **快照文件 0600 / 目录 0700**：快照含用户编辑过文件的全文，权限对齐 DSH 自有存储惯例
- **命令原文不进投影**：shell 命令可能带 inline 凭据，插件只存 `callId` 和一个用于同轮去重的短哈希，原文按需从日志读
- **命令级敏感隐藏**：命令确实读写敏感文件时（剥掉 heredoc 正文后按路径形状判断 token）整条隐藏，不去猜哪一段是密钥
- **无网络外发**：零出站请求，只在本机 HTTP 路由内取回会话日志内容
- **纯 JSON 投影状态**：state 不含 `Map`/`Set` 或值为 `undefined` 的键，保证 `session-projection-cache` 的无损 JSON 检查通过（否则整条会话检查点会被拒，连带内置投影一起丢）
- **有界增长**：pending 调用、shell 索引、单文件编辑/被拒记录（200/50）、改动记录轮数（100）、快照文档体积（12MB）、进程内快照缓存全部有上限，长会话与多会话都不会无界增长

## 原理

数据来自 `sessionProjections`，从会话日志实时重放。投影只存轻量索引（每处编辑的 `callId`、工具、轮次、起始行号）；前端通过 `kind:"whole"` 一个请求取回全文对照的全部原料（磁盘当前内容 + 两份快照 + 片段史），按 `callId` 取回单条 diff 或命令原文。

绝对行号来自写入工具在 `tool/result` 里带的 applied diff；某些 `write` 调用不带这份元数据，此时回退到 `tool/call` 参数取内容，行号降级为块内相对行号并在 UI 上标明。

**全文对照的两份快照**（落盘于 `~/.dsh/storages/what-changed-sidebar/<会话id>.json`，内容按 sha1 去重存储——同一份文件内容只存一份，相邻轮次内容未变时体积从 O(轮数) 降到 O(1)；写入为异步原子写：临时文件 + 改名）：`tool/call` 事件在工具执行前提交，此时读盘得到的就是「改前」；`turn/end` 时把本轮碰过的文件逐个读盘落定为该轮「改后」——所以本轮期间的 shell 写入也如实包含在内。投影另存一个 `lastEndedTurn`（已结束的最大轮号），它在 `turn/end` 时变化，前端据此拉取快照，把「本轮进行中…」换成可点的「全文对照」。只有 shell 写入、没有任何编辑工具调用的文件拿不到改前快照，因此没有全文对照，只有逐次修改里的 shell 命令组。

**大文件的 diff**：逐行 LCS 的 DP 有 300×300 上界，超出时先找"两侧都唯一出现"的公共行当锚点（patience diff 思路）分段递归，每段落回 DP——全文对照对大文件不再退化成整段红加整段绿；总行数超 6000 时截断并标注剩余行数。

## 安装

```sh
dsh plugin --profile web add dsh-what-changed-sidebar
```

或按本地路径 / GitHub 仓库安装：

```sh
dsh plugin --profile web add /path/to/dsh-what-changed-sidebar
dsh plugin --profile web add github:btyawcy/dsh-what-changed-sidebar
```

装完重启 `dsh web`（host 半边的投影与路由需重启进程），浏览器硬刷新即可。

## 与 dsh-what-changed 的关系

本插件是 [dsh-what-changed](https://github.com/sjh9714/dsh-what-changed) 的**展示层重做版**：复用它的投影收集思路，把「顶栏按钮 + 弹面板」换成「better-sidebar 侧边栏 tab」，并加入倒序与次序编号、懒加载索引化、轮次快照的全文对照、shell 命令原文、敏感防护、跳转/复制等能力。
